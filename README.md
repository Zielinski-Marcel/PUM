# Mobile Sports Application

A mobile running application built with Flutter and integrated with an API.

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Zielinski-Marcel/PUM.git
```

### 2. Navigate to the Project Directory

```bash
cd PurofessorMobile
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

```bash
flutter run
```

## Requirements

- Flutter SDK
- Dart SDK
- An Android or iOS device, or an emulator
- Access to the API used by the application
